# geometric_lib

Библиотека на Python для вычисления площади и периметра базовых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Общее описание

Библиотека разбита на отдельные модули по одному на каждую фигуру. В каждом модуле лежат две функции с одинаковыми именами - `area` (площадь) и `perimeter` (периметр).

На вход функции принимают линейные размеры фигуры (сторону, радиус, высоту) в виде числа `int` или `float`, на выходе отдают такое же число - результат вычисления по стандартной геометрической формуле. Никакой проверки входных данных (отрицательные числа, строки и т.п.) библиотека не делает - предполагается, что вызывающий код передаёт корректные значения.

## Состав проекта

| Файл           | Фигура        | Функции                            |
| -------------- | ------------- | ---------------------------------- |
| `circle.py`    | Круг          | `area(r)`, `perimeter(r)`          |
| `rectangle.py` | Прямоугольник | `area(a, b)`, `perimeter(a, b)`    |
| `square.py`    | Квадрат       | `area(a)`, `perimeter(a)`          |
| `triangle.py`  | Треугольник   | `area(a, h)`, `perimeter(a, b, c)` |

## circle.py

### `area(r)`

Площадь круга по формуле S = πr².

**Параметры:**

- `r` (`float | int`) - радиус круга

**Возвращает:** `float` - площадь круга

**Пример:**

```python
import circle

circle.area(5)      # 78.53981633974483
circle.area(2.5)    # 19.634954084936208
```

### `perimeter(r)`

Периметр (длина окружности) по формуле P = 2πr.

**Параметры:**

- `r` (`float | int`) - радиус круга

**Возвращает:** `float` - периметр круга

**Пример:**

```python
import circle

circle.perimeter(5)    # 31.41592653589793
```

## rectangle.py

### `area(a, b)`

Площадь прямоугольника по формуле S = a·b.

**Параметры:**

- `a` (`float | int`) - длина первой стороны
- `b` (`float | int`) - длина второй стороны

**Возвращает:** `float | int` - площадь прямоугольника

**Пример:**

```python
import rectangle

rectangle.area(3, 4)    # 12
```

### `perimeter(a, b)`

Периметр прямоугольника по формуле P = 2·(a + b).

**Параметры:**

- `a` (`float | int`) - длина первой стороны
- `b` (`float | int`) - длина второй стороны

**Возвращает:** `float | int` - периметр прямоугольника

**Пример:**

```python
import rectangle

rectangle.perimeter(3, 4)    # 14
```

## square.py

### `area(a)`

Площадь квадрата по формуле S = a².

**Параметры:**

- `a` (`float | int`) - длина стороны квадрата

**Возвращает:** `float | int` - площадь квадрата

**Пример:**

```python
import square

square.area(5)    # 25
```

### `perimeter(a)`

Периметр квадрата по формуле P = 4a.

**Параметры:**

- `a` (`float | int`) - длина стороны квадрата

**Возвращает:** `float | int` - периметр квадрата

**Пример:**

```python
import square

square.perimeter(5)    # 20
```

## triangle.py

### `area(a, h)`

Площадь треугольника по формуле S = a·h / 2, где `a` - основание, `h` - высота, проведённая к этому основанию.

**Параметры:**

- `a` (`float | int`) - длина основания треугольника
- `h` (`float | int`) - высота, проведённая к основанию `a`

**Возвращает:** `float | int` - площадь треугольника

**Пример:**

```python
import triangle

triangle.area(4, 3)    # 6.0
```

### `perimeter(a, b, c)`

Периметр треугольника по формуле P = a + b + c.

**Параметры:**

- `a`, `b`, `c` (`float | int`) - длины сторон треугольника

**Возвращает:** `float | int` - периметр треугольника

**Пример:**

```python
import triangle

triangle.perimeter(3, 4, 5)    # 12
```

## Сводная таблица формул

### Площадь

- Круг: S = πR²
- Прямоугольник: S = ab
- Квадрат: S = a²
- Треугольник: S = a·h / 2

### Периметр

- Круг: P = 2πR
- Прямоугольник: P = 2a + 2b
- Квадрат: P = 4a
- Треугольник: P = a + b + c
